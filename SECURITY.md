# Reporting a security issue

Use the repository's private security form for possible vulnerabilities. Include the Render Bridge version, operating system, what you observed, and the steps needed to reproduce it. Remove tokens, signed file links, private hostnames, and personal paths before sharing diagnostics. [Report a vulnerability privately](https://github.com/BlackRune-LLC/render-mcp-bridge/security/advisories/new)

For setup questions and ordinary bugs, use the public support issue tracker. [Open a support issue](https://github.com/BlackRune-LLC/render-mcp-bridge/issues/new)
